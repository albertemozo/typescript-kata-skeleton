# 💀 Typescripy Kata Skeleton

A simple skeleton for Typescript katas.

## Requirements
- One of the following:
    - Node 24+
    - Docker
- Make (optional)

## Usage with Docker

Build the image.

```shell
make build
```

Check everything works.

```shell
make test
```

## Usage with local Node.js

Install dependencies.

```shell
npm install
```

Check everything works.

```shell
npm test
```
